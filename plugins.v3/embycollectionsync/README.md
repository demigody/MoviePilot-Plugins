# 媒体库片单管理 1.0.1 · MoviePilot V3

**Media Library Playlist Manager**

管理电影和电视剧片单，支持 TMDB 合集一次性导入与持续关注；支持 Emby、Jellyfin、Plex，按媒体库同步合集或播放列表，并提供预览、创建、增删、校验、排序和重排，可选自动订阅及入库后自动同步。

EmbyCollectionSync 首次公开发布。将维护者的 MoviePilot 插件仓库添加到插件市场来源并刷新，然后安装“媒体库片单管理”，在插件详情中启用。

首次使用时新建片单并添加媒体，再进入“媒体库同步”选择 MoviePilot 已配置的 Emby、Jellyfin 或 Plex，设置合集或播放列表并执行同步。添加媒体默认不会触发订阅或下载；自动任务需在片单设置中显式开启。

插件管理电影与电视剧片单、TMDB 合集来源、各 媒体库 目标的合集和播放顺序。电视剧可选全部季或指定季，每个作品 ID 仍只占一项。默认添加成员不会订阅或下载。支持多目标，服务器 ID 与各输出绑定分别保存。

媒体库同步支持 Emby、Jellyfin 与 Plex。先完成分页和输出读取，再添加、校验、重排、移除。Emby/Jellyfin 全部季的合集使用 Series，指定季使用 Season；播放列表按所选范围展开已入库剧集。Plex 复用 MoviePilot 中的地址和令牌，无需额外登录；混合类型或指定季时关闭合集并说明原因，跨媒体库合集在写入前拒绝，播放列表可混合电影和剧集。Plex 连接变化或含糊的 404 保留旧绑定并停止，不自动接管。自动订阅只添加所选范围内缺少的季，入库识别延迟采用三次退避重试，同批更新同一条记录。Jellyfin 通过 Quick Connect 自动取得并缓存播放列表用户令牌；预览不创建授权会话。

页面加载入口 `dist/assets/remoteEntry.js`，导出 Page、AppPage、Config、MediaActions。Config 复用统一管理页，通过插件 API 保存设置和片单；不发送会整体覆盖配置的宿主 `save` 事件。

片单页面支持单条或全部导出为带版本号的 MoviePilot JSON 文件，文件名使用片单名称。导入文件会先预览，可编辑片单名称并选择要导入的片单；影片、合集名称、播放列表及其顺序会保留。原媒体服务器和媒体库范围不会导入，用户在片单的“媒体库同步”页重新选择。导入的片单默认停用，自动订阅及入库后自动同步关闭，远端绑定不会跨服务器复用；名称重复时须修改后再导入。

Trakt 公开片单导入使用插件内置的公开 Client ID，用户无需自行注册应用或授权登录。支持 `trakt.tv` 与 `app.trakt.tv` 的公开片单链接；私有列表、单集条目和没有 TMDB 身份的条目不会静默导入。
